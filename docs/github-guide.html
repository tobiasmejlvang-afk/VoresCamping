Trin-for-trin

Udgiv Vores Camping på GitHub Pages

Appen udgives direkte fra main-branchens /docs-mappe – uden npm, build-trin eller en brugeroprettet GitHub Action.

1. Upload den nye version

Pak ZIP-filen ud

Pak Vores-Camping-v16.zip ud på computeren.

Åbn dit repository

Åbn repositoryet på GitHub og gå ind i den eksisterende docs-mappe.

Erstat de gamle appfiler

Upload indholdet fra den nye docs-mappe. Sørg for, at filen ender som docs/index.html – ikke docs/docs/index.html.

Commit til main

Vælg at gemme direkte på main-branchen og brug eksempelvis committeksten “Opdater Vores Camping til version 16”.

docs/
├── index.html
├── app.js
├── maps.js
├── ors.js
├── styles.css
├── manifest.webmanifest
├── github-guide.html
├── .nojekyll
└── assets/

2. Aktivér GitHub Pages

Åbn Settings

Vælg repositoryets Settings og derefter Pages.

Vælg udgivelseskilde

Under Build and deployment vælges Deploy from a branch.

Vælg main og /docs

Vælg branchen main, mappen /docs og tryk Save.

Åbn appens adresse

Vent på udgivelsen og åbn adressen, GitHub viser på Pages-siden. Det kan tage nogle minutter, før ændringen er synlig.

3. Kontrollér appen

Forsiden åbner✓
Logo og hurtigknapper vises✓
Sisi og uret vises kun på Overblik✓
Kortet indlæses✓
Indstillinger og backup virker✓

4. Openrouteservice

Gå tilbage til appen, åbn Indstillinger → Kort og API-nøgler, indsæt din nøgle, test forbindelsen og gem. Nøglen skal ikke skrives ind i repositoryets JavaScript-filer.

Kortvisningen kan bruges uden ORS-nøgle. Online søgning, geokodning og udvidet ruteberegning kræver nøglen.

Fejlfinding

404-fejl

Kontrollér Pages-kilden, main /docs, og at docs/index.html findes.

Gammel version

Brug Ctrl + F5, vent nogle minutter og kontrollér, at committen ligger på main.

Kortet fejler

Kontrollér internetforbindelsen. Appen forsøger automatisk at skifte til et reservekort.

Ruten kan ikke beregnes

Test Openrouteservice-nøglen i Indstillinger og kontrollér, at ruten har mindst to punkter.
