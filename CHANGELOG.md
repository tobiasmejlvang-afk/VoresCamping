# Ændringer i version 12

- Nyt lyst, varmt og kompakt campingdesign baseret på de vedhæftede layouts.
- Nyt personligt logo, cover, eksempelbilleder og Sisis nedtællingsur.
- Nyt samlet dashboard med kort, hurtige handlinger, statistik og dynamiske sektioner.
- Separate sider til besøgte steder, kort, rangliste, ønskeliste og indstillinger.
- Fuld oprettelse, redigering, sletning og statusændring af campingpladser.
- Vurderingskategorier, kategorivindere og automatisk rangering.
- Billedkomprimering, galleri, seværdigheder, private noter og tags.
- Cykelrute-editor med Openrouteservice og Google Maps-links.
- OpenFreeMap/MapLibre med Google Maps som valgfri reserve.
- Automatisk geokodningsreserve via OpenStreetMap, hvis ORS fejler.
- Lokal lagring, datamigrering, JSON-backup og fjernelse af API-nøgler fra backup.
- Hash-navigation til GitHub Pages og tydelig fejlvisning i stedet for hvid skærm.
- Responsiv sidemenu på computer og bundnavigation på tablet/mobil.
