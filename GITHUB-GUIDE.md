# GitHub Pages-guide

1. Opret eller åbn repositoryet til Vores Camping.
2. Slet den gamle `docs/`-mappe, så filer fra tidligere versioner ikke blandes med den nye app.
3. Upload den nye `docs/`-mappe fra v22.
4. Upload også README og øvrig dokumentation efter behov.
5. Commit direkte til `main`.
6. Åbn **Settings → Pages**.
7. Vælg **Deploy from a branch**.
8. Vælg branch **main** og mappe **/docs**.
9. Gem og vent på GitHub Pages-linket.

Efter udgivelsen bør siden åbnes i et privat vindue første gang. Denne udgave bruger dog nye filversioner og en ny localStorage-nøgle, så den forsøger ikke at overtage gamle data.
