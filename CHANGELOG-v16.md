# Ændringslog – Vores Camping v16

## Forsiden

- Nyt kompakt Campingpuls-panel med næste ønskemål, bedst bedømte sted og seneste cykelrute.
- Finpudset hurtig-handlingsområde med nyt design og direkte adgang til ny cykelrute.
- Nyt hovedlogo er standard for nye og migrerede installationer.

## Sisi og nedtællingsuret

- Uret og Sisi er bygget som separate lag, så nedtællingstallene ligger præcist i urets fire displayfelter.
- Widgeten vises som standard kun på Overblik.
- Placeringen kan låses og låses op.
- Oplåst widget kan flyttes med mus eller finger på forsiden.
- Valg mellem fire hjørner, størrelse, afstand, gennemsigtighed og visning af ekstra tekst.
- Animationstyper: Fra, Rolig, Glad og utålmodig samt Fuld eventyr-mode.
- Automatisk mere ivrig animation tæt på afgang.
- Klikbart jubelhop og respekt for enhedens indstilling om reduceret bevægelse.

## Cykelruter

- Standardprofil, rutetype, underlag og pausetid kan vælges i Indstillinger.
- Flere felter i ruteeditoren.
- Naturskøn prioritering og forsøg på at undgå trafik kan gemmes som rutedata.
- Højdepunkter, stop og ekstra rutenoter.
- GPX-eksport fra editor og detaljevisning.
- Duplikering af en eksisterende rute.

## GitHub Pages

- Tilføjet `.nojekyll` i `/docs`.
- Tilføjet indbygget HTML-guide og separat Markdown-guide.
- Settings-siden linker direkte til guiden.
